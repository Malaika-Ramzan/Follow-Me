# FOLLOWME.

### Design That Moves With You.

FollowMe is a premium, fully responsive and interactive website, designed and developed with HTML, CSS and JavaScript.

It features a unique live cursor-following creature animation that moves smoothly across the screen, giving visitors a beautiful and memorable experience.

---

## Live Demo

> Open `index.html` in any modern browser to view the website.
> No installation or setup is required.

---

## Features

- Live Interactive Creature Animation
- Smooth Scrolling One-Page Design
- Home, About, Services, Portfolio and Contact Sections
- Fully Responsive Design for Mobile, iPhone, iPad, Laptop and PC
- Dark Mode and Light Mode
- Clean, Premium and Modern Layout
- Fast Loading and Lightweight Code
- Mobile Friendly Navigation Menu
